## What I build

- **ATLAS** — a hands-free, CLI-native voice assistant built on Claude. Streaming speech in and out, tool orchestration, session memory.
- **AI Mystery Shopper** — an autonomous agent that audits e-commerce storefronts the way an AI assistant shops them. Every run instrumented in tokens and dollars.
- **SkinAI** — an iOS skin-analysis app with a vision-LLM pipeline. Designed, built, and shipped to TestFlight end-to-end.
- **Production automation** — a Cloudflare Worker pipeline (ClickUp → Slack) computing daily reports and invoices for a UK agency. Running unattended in production, every day.
- **[This portfolio](https://github.com/erfanveisi2/ai-portfolio)** — a machine-OS WebGL experience: 9k dot-matrix particles, generative WebAudio soundtrack, scroll-driven story.
